| **主旨**   | 探討利用反向設計（Topology Optimization, TO）方法，設計介電腔體實現遠距離量子發射體（Quantum Emitters, QEs）對的穩態最大糾纏 Bell 態。                                                                         |
| **探討**   | - 設計腔體幾何（R＝6.25λ，h＝16.67λ，λ＝600nm）、發射體偶極矩（∥p∥＝1e·nm），目標為偶對稱與奇對稱 Bell 態。  <br>- 發射體頻率失諧（∥δi∥/γ₀＝0.2）、雷射泵浦強度（∥Ωi∥/γ₀＝0.7），雷射場組合依奇偶對稱決定。  <br>- 發射體間距下限由繞射極限定為 d₁₂≳λ/21。 |
| **結果**   | - 腔體能於λ至4λ間距下，對偶/奇 Bell 態保真度（F₊±）皆>0.95，純度P₊±＞0.98；基態佔據數 n_G^₊± ≈0.04，隨距微幅上升。  <br>- 保真度及純度主要因裝置有限尺寸導致隨距離略降。  <br>- 腔體設計具有高魯棒性，能容忍QE位置微小偏移1。                          |

| **設計特點** | - 腔體需動態調控Purcell因子（γ^₊±/γ₀）；近距時Purcell增強至1.5倍，遠距時強烈抑制至約0.1，調節範圍達15倍。  <br>- 支持不同距離下穩態糾纏的形成1。                                                                          |
| **優化過程** | - 以d₁₂＝3.4λ奇對稱腔體為例，最初Purcell值劇降、耗散耦合迅速增大。  <br>- 保真度隨著優化步數線性提升，最終達F₊±＝0.96，並實現理想參數（γ₁₂＝γ, g₁₂＝0）。                                                                     |
| **結構解析** | - 優化後腔體展現兩主區結構：腔體邊緣橢圓高對比反射器，降低輻射；QE近場為低對比球殼，調控交互作用。  <br>- 兩區間穿插高介電環，有效優化「光子輔助交互」與「光子洩漏」平衡；最大介電常數僅適中，保證裝置可行性。                                                         |
